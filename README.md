# Tropical Precipitation Response to Anthropogenic Climate Change in Recent Decades

Raw data and codes used to plot the figures of 'Tropical Precipitation Response to Anthropogenic Climate Change in Recent Decades' published in Nature Communications.



This repository contains the figure-generation and analysis codes and data used in the study:



“Tropical precipitation response to anthropogenic climate change.”

(published in Nature Communications)



The scripts are designed to reproduce the key figures and diagnostics presented in the manuscript.
